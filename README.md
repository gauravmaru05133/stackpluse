# stackpluse

Modern SaaS landing & inquiry site built with **React + Vite**.

## Stack

- React 19 + Vite
- Tailwind CSS v4
- Framer Motion (scroll reveals & micro-interactions)
- Lenis (smooth scrolling)
- Lucide icons

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```
